# 决策规则速查 — C程序设计（第五版）

| 能力 | 一句话规则 |
|---|---|
| C 程序骨架与编译运行 | 先认清错误出现在编译期还是运行期，再决定改语法还是查逻辑。 |
| 算法先行：从任务到算法的设计流程 | 先把任务拆成算法与模块再写代码；重复操作找规律改写为循环。 |
| 控制结构选型与陷阱 | 常量多分支用 switch、范围判断用 if；可能一次不执行用 while、至少一次用 do-while。 |
| 数组与字符串处理批量数据 | 定义长度 N 就一律写 for(i=0;i<N;i++)，合法下标只到 N-1。 |
| 函数、参数传递与递归 | 想在函数里改调用者的变量，就传地址而不是传值。 |
| 指针：地址模型与间接访问 | 指针就是地址；地址带类型，所以指针必须指定基类型，且用前必须指向合法对象。 |
| 结构体与链表 | 结构体类型不占空间、变量才占；链表尾结点 next 必须置 NULL。 |
| 文件读写：打开—读写—关闭 | 打开必须判空、用完必须 fclose，否则缓冲区数据会丢。 |
| 调试与测试 | 跑通一组数据不等于正确；必须测边界值。 |
| 术语速查（C 程序设计核心概念） | 指针≠指针变量、常量≠常变量、定义≠声明——先分清边界再谈用法。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
