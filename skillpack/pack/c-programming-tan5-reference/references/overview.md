# C程序设计（第五版）· 整书概览

- **书名**：C程序设计（第五版）
- **作者**：谭浩强
- **出版**：清华大学出版社，2017 年（ISBN 978-7-302-48144-7）
- **标准依据**：C99
- **读者定位**：没有学过计算机程序设计的大学生；也适合自学

## 一句话主旨

用尽量少的语法概念、配合大量可运行实例，把零基础读者带到「能独立写出结构化 C 程序、理解指针与文件」的程度。

## 骨架（十章递进）

1. **程序设计与 C 语言**（第1章）——程序是计算机能识别和执行的指令序列；C 程序由函数组成，必须有且仅有一个 `main`；从源码到运行要经过编辑、编译（预处理＋语法检查）、连接（装配库）、运行四步。
2. **算法——程序的灵魂**（第2章）——程序 = 算法 + 数据结构。算法有五个特性（有穷性、确定性、零个或多个输入、一个或多个输出、有效性）；可用自然语言、流程图、N-S 图、伪代码表示；任何算法都能由顺序、选择、循环三种基本结构组合而成；结构化程序设计的方法是自顶向下、逐步细化、模块化、结构化编码。
3. **顺序程序设计**（第3章）——常量与变量、数据类型、运算符与表达式、C 语句、输入输出。变量必须先定义后使用；符号常量用 `#define`、常变量用 `const`。
4. **选择结构**（第4章）——`if` 处理双分支（含嵌套与悬空 else），`switch` 处理多分支（注意 case 穿透），条件运算符 `?:` 是三目运算符；关系与逻辑表达式的结果为 1（真）或 0（假），逻辑运算存在短路求值。
5. **循环结构**（第5章）——`while` 先判断后执行、`do…while` 先执行后判断（至少一次）、`for` 最灵活；循环体内必须有使循环趋于结束的语句；`break` 终止整个循环，`continue` 只结束本次。
6. **数组**（第6章）——一维、二维、字符数组。下标从 0 开始，`int a[10]` 的合法下标是 0~9；C 不做越界检查；字符串以 `'\0'` 结尾。起泡排序是双重循环的经典范式。
7. **函数**（第7章）——函数就是功能，函数名应见名知义；定义在调用之后必须先声明；实参向形参是**单向值传递**，要改调用者变量必须传地址；递归必须同时有递归关系与终止条件，执行分「回溯」与「递推」两阶段。
8. **指针**（第8章，全书重点与难点）——**指针就是地址**；C 的地址是「带类型的地址」，所以定义指针必须指定基类型；区分指针、指针变量、基类型三者；指针用前必须指向合法对象（区分未赋值／`NULL`／有效三态）。
9. **用户自己建立数据类型**（第9章）——结构体把不同类型成员组成一个实体（类型不占空间、变量才占）；共用体成员共享同一段存储；枚举取值限于所列常量；`typedef` 只是起别名。自引用结构 + 指针构成链表，尾结点 `next` 必须置 `NULL`。
10. **文件的输入输出**（第10章）——文件是外部介质上数据的集合；C 把文件看作字符流；操作固定为「打开（必须判空）—读写—关闭（必须调用）」三步；写数据先进缓冲区，不 `fclose` 会丢数据。

## 作者的教学主张

- **先算法后编码**：每个例题都按「提出任务 → 解题思路 → 编写程序 → 运行结果 → 程序分析 → 有关说明」展开，而不是先列程序再解释。
- **降低门槛**：定位准确、取舍恰当、结构合理、概念清晰、循序渐进，善于把复杂问题简单化。作者的原话是"只有明白'不明白的人为什么不明白'的人才是明白人"。
- **重视实践**：学得好坏不是看"知不知道"，而是"会不会干"；考核应是编写与调试程序，而非是非题选择题。
- **举一反三**：学语言是为了学程序设计方法；掌握算法后换语言并不困难。

## 这本书的局限（读它要打的折扣）

1. **标准偏旧**：基于 C99，未覆盖 C11/C17/C23 的新特性（`_Generic`、线程、原子操作、`bool` 的更完整支持等）；示例环境是 Visual C++ 6.0 / VS2010。
2. **不涉工程实践**：没有构建系统（Makefile/CMake）、版本控制、单元测试框架、静态分析、sanitizer、调试器进阶用法。
3. **示例是教学规模**：例题程序"规模一般都不大"，缺少多文件项目、接口设计、真实数据规模下的性能与健壮性考量。
4. **部分内容已外移**：第5版把「位运算」「预处理指令」「常见错误分析（35 种）」「C 程序应用案例」移到了配套的《学习辅导》一书，正文并不完整覆盖这些主题。
5. **指针讲法有效但有限**：以"地址＝房间号"为核心比喻，对理解 `&`/`*` 极为有效，但不涉及所有权、生命周期、悬垂指针、别名与优化等现代内存话题。
6. **链表仅简介**：作者明言对非计算机专业"难度较大"，正文只作简单介绍，详细内容在习题与辅导书中。

> 以上局限已写入各能力卡的 B（Boundary）段，用于防止在不适用场景误用。
