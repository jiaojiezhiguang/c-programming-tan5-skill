## 1. 数列排序 （`sequence_sort.c`）

**题目**：给定长度为 n 的数列，从小到大排序。`1 <= n <= 200`，每个整数绝对值 < 10000。
输出一行，数字间用空格分隔。

| 样例输入 | 样例输出 |
|---|---|
| `5`<br>`8 3 6 4 9` | `3 4 6 8 9` |

**用到的知识**：第 1 章程序结构、第 3 章输入输出、第 5 章循环、第 6 章数组、例 6.3 起泡法
**未使用**：第 7 章函数、第 9 章结构体、第 10 章文件

### 代码

```c
#include <stdio.h>

#define N 200            /* 题目给定 n <= 200，用符号常量做数组长度 */

int main()
{
    int a[N];
    int n;
    int i, j, t;

    /* 1. 读入数据 */
    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%d", &a[i]);

    /* 2. 起泡法升序排序 */
    for (j = 0; j < n - 1; j++)            /* 外层：n 个数需 n-1 趟 */
        for (i = 0; i < n - 1 - j; i++)    /* 内层：第 j 趟比 n-1-j 次 */
            if (a[i] > a[i + 1]) {
                t = a[i];
                a[i] = a[i + 1];
                a[i + 1] = t;
            }

    /* 3. 输出 */
    for (i = 0; i < n; i++) {
        if (i > 0) printf(" ");
        printf("%d", a[i]);
    }
    printf("\n");

    return 0;
}
```

### 三个关键点

**① 为什么内层是 `n-1-j` 而不是 `n-1`**

每趟结束，当前最大数会"沉底"到末尾。第 1 趟（j=0）比较 n-1 次，把最大数放到 `a[n-1]`；
第 2 趟（j=1）时 `a[n-1]` 已到位，只需比较 n-2 次；依此类推，第 j 趟比 `n-1-j` 次。

写成固定的 `n-1` 不算错，只是多做无用比较，属于性能问题。

**② 下标为什么是 `i` 和 `i+1`，上界为什么减 1**

因为要比较**相邻**两个元素，`a[i]` 与 `a[i+1]`。如果 `i` 能取到 `n-1`，
`a[i+1]` 就是 `a[n]`——**越界**了（`int a[200]` 的合法下标是 0~199）。
所以内层上界必须是 `n-1-j`，保证 `i+1 <= n-1`。

**③ 交换为什么必须借第三个变量 `t`**

```c
t = a[i];        /* ① 先把 a[i] 存到 t，防止被覆盖 */
a[i] = a[i + 1]; /* ② 现在可以放心把 a[i+1] 写进 a[i] */
a[i + 1] = t;    /* ③ 再把原来的 a[i] 写到 a[i+1] */
```

如果直接写：
```c
a[i] = a[i + 1];   /* 此时 a[i] 的原值已被销毁 */
a[i + 1] = a[i];   /* 只是把刚写进去的值又写一遍，两个位置变成同一个数 */
```
这就是教材例 4.2 讲的"两个杯子换水，必须借第三个杯子"。

### 复杂度

- 时间复杂度：O(n²)，n=200 时最坏约 20000 次比较，瞬间完成
- 空间复杂度：O(n)，一个 200 元素的数组

题目规模小，起泡法足够。若 n 到 10⁵ 量级，需要换 O(n log n) 的算法（排序库函数或快排），
但那超出了目前学的范围。

### 容易踩的坑

1. **`scanf("%d", &a[i])` 漏 `&`** —— 会把 `a[i]` 的值当地址用，写入随机内存（教材 §3.5.4）
2. **数组开小** —— 题目说 n ≤ 200，就要能装下 200 个，`int a[200]` 刚好；开 199 会在 n=200 时越界
3. **循环写成 `i <= n`** —— 越界访问 `a[n]`，C 不检查，可能悄悄改坏别的变量
4. **输出末尾多一个空格** —— 多数 OJ 能容忍行末空格，但严格的会判格式错误；用 `if (i > 0) printf(" ")` 更稳
5. **忘记 `return 0;`** —— 不算错，但养成习惯
